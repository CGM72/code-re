# Verilog Practice: 2-to-1 Multiplexer (MUX)
# Verilog 연습: 2:1 멀티플렉서(MUX)

## Problem / 문제
**EN:** Design a 2-to-1 multiplexer using Verilog. When `sel` is 0, output `a`; when `sel` is 1, output `b`.

**KO:** Verilog로 2:1 멀티플렉서를 설계하세요. `sel`이 0이면 `a`를, 1이면 `b`를 출력하세요.

## Requirements / 조건
- **EN:** Use a continuous assignment (`assign`) and the ternary operator (`? :`).
- **KO:** 연속 할당문(`assign`)과 삼항 연산자(`? :`)를 사용하세요.
- **EN:** Use the ports `a`, `b`, `sel`, and `y`.
- **KO:** 포트 `a`, `b`, `sel`, `y`를 사용하세요.

## Hint / 힌트
- **EN:** The ternary operator chooses between two expressions based on a condition.
- **KO:** 삼항 연산자는 조건에 따라 두 표현식 중 하나를 선택합니다.
